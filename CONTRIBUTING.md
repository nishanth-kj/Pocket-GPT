# Contributing to Pocket GPT

First off, thank you for considering contributing to Pocket GPT! It's people like you that make Pocket GPT such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check if there's already an issue for it. If not, go ahead and open a new issue!

## Branching Strategy
- `main`: The stable production branch.
- `Android`: Active development branch for the Android application.
- `site`: Active development branch for the Next.js landing page.

Please create a new branch from `main` (or the respective component branch) for your feature or bugfix:
`git checkout -b feature/your-feature-name`

## Pull Requests
1. Ensure your code follows the existing style conventions.
2. Update documentation if necessary.
3. Open a Pull Request against the `main` branch.
4. Provide a clear and descriptive PR description.
