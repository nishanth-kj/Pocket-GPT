# Getting Started

## Android App (`/android`)

### Prerequisites
- Android Studio (Latest Stable)
- Java JDK 17+
- Android SDK API Level 34+

### Running the App
1. Open Android Studio.
2. Select **File > Open** and choose the `android/` directory in this repository.
3. Wait for Gradle to sync dependencies.
4. Click the **Run** button to launch the app on an emulator or physical device.

---

## Landing Page (`/site`)

### Prerequisites
- Node.js (v20+)
- npm or yarn

### Running the Site Locally
1. Open a terminal and navigate to the `site` directory:
   ```bash
   cd site
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
